# voxlog-feature:settings

Global settings, speech and search models, optional AI providers, HTTP hooks, sync and export, plus category (including pinned shortcuts) and label management.

**May depend on:** `core/*`, `engine/llm` (error types).

## Entry points

- `SettingsRoute`, `settingsScreens()`
- `SettingsScreen`, `SettingsActions`
- `CategoriesScreen`, `CategoryEditorScreen`, `LabelsScreen`, `ShortcutPinner`
