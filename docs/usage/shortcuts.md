# Shortcuts and fast capture

| Shortcut | How to get it | What it does |
|---|---|---|
| **Voice note** | Long-press the VoxLog icon | Starts recording into your default category |
| **Text note** | Long-press the VoxLog icon | Opens the composer in your default category |
| **Record into <category>** | Long-press the VoxLog icon (your first two categories appear automatically) | Starts recording into that category |
| **Quick Settings tile** | Pull down the notification shade → edit tiles → drag **Voice note** in | Starts recording from anywhere |
| **Pinned category shortcuts** | Settings → Categories → a category → *Add voice shortcut* / *Add text shortcut* | Adds a home-screen icon that captures straight into that category |

Tips:

- Drag a shortcut from the long-press menu to the home screen for one-tap recording.
- You can change the category on the record screen while you talk; the note is saved into whatever
  category is selected when you press Stop.
- Set the **default category** in Settings → Capture.
- Notes keep which shortcut created them (visible in exports), which is handy for automations.
