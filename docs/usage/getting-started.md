# Getting started

## Install

- **F-Droid:** search for VoxLog once it's in the main repository, or add the developer repository
  `https://mikejhill.github.io/voxlog/fdroid/repo` in the F-Droid or Droid-ify client.
- **Direct:** download the APK from GitHub Releases, or track releases with Obtainium.

All three channels ship the same signed APK, so you can switch between them without reinstalling.

## First launch

VoxLog downloads two models in the background on first launch (Wi-Fi recommended):

| Model | Size | Used for |
|---|---|---|
| Whisper base (English) | 60 MB | Turning speech into text, on the device |
| MiniLM | 23 MB | Finding related notes by meaning |

You can record before the downloads finish; transcription starts as soon as the speech model arrives.
Change the speech model in **Settings → Speech to text** (tiny is fastest, small is most accurate,
"multilingual" understands languages other than English).

## Your first voice note

1. Tap **Record**. Allow microphone access the first time.
2. Talk. There's no time limit, and the screen can turn off. The notification has a Stop button.
3. Tap **Stop**. The note is saved immediately and the screen closes by itself.
4. The transcript appears on the note a moment later.

## Your first text note

Tap the pencil button (or the **Text note** shortcut), type, and tap **Save**. The title starts as
the current date and time; change it if you like.

## Editing

Open any note to edit its title or text (saved automatically), change its category, add labels, play
or delete its audio, or see its details: when, how long, where (if location is on), and how it was
captured.
