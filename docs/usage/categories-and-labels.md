# Categories and labels

## Categories

Every note is in exactly one category. **Uncategorized** always exists; it can't be renamed or
deleted, but its settings can be changed.

Per-category settings (Settings → Categories → a category):

| Setting | Effect |
|---|---|
| Save audio | Keep the recording (about 0.5 MB per minute) or keep only the text. |
| Default labels | Added to every note captured into the category. |
| Clean up / auto-name / auto-label with AI | Run these AI tasks for notes captured here, even if they're off globally. |
| Shortcuts | Pin voice or text shortcuts that capture straight into this category. |

Capture-time settings (save audio, default labels) apply when a note is captured. Moving a note to
another category later doesn't add labels or delete audio.

Deleting a category moves its notes to Uncategorized; no notes are deleted.

## Labels

Notes can have any number of labels. Add them from a note's detail screen; manage (rename, delete) them
in Settings → Labels.

## Filtering

On the notes screen:

- Tap a category chip to show one category, or **All**.
- Tap label chips to filter by labels across categories. With two or more labels selected, toggle
  between **Any label** and **All labels**.
- Category and label filters combine.
