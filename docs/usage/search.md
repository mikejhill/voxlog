# Search

Tap the search icon and type. Results come in two groups:

1. **Matches**: notes containing all of your words (prefixes count, so "tomat" finds "tomatoes"),
   best first. Title matches rank above body matches.
2. **Related notes**: notes with a similar meaning that don't contain the exact words, for example
   "doctor visit" finding a note about "appointment with Dr. Lee". This needs semantic search to be on
   (Settings → Search) and its model to be downloaded.

Use the category chips to search within one category. Everything runs on the device.
